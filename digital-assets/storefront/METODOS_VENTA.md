# Métodos de venta — Activos digitales LEGIÓN

## 1. Directo (recomendado para arrancar)
- **Gumroad** o **Lemon Squeezy**: sube cada `dist/*.tar.gz` + listing
- **itch.io**: ideal para Solar Lab y juegos HTML (pay-what-you-want o fijo)

## 2. Drive + pago
- Carpeta Drive “COMPRAS” con link solo tras pago (PayPal/Stripe)
- Entrega: tar.gz + .sha256

## 3. Lead magnet → upsell
- FREE: PROMPT_PEGABLE + Solar Lab lite
- Pago: Bundle + Skills Ultra + Engineering Kit

## 4. B2B / licencia
- Kit FORJA como process para estudios
- White-label del lab con su marca (LIC-WHITE)

## 5. Suscripción
- Patreon: builds mensuales mutados (FORJA candidates)

## Checklist pre-publicación
- [ ] SHA256 del tar coincide
- [ ] README con ≤3 pasos
- [ ] LICENSE clara (personal vs comercial)
- [ ] No incluir secretos, auth.db, ni datos personales del Mando
- [ ] Canon 12.3 hasheado si se incluye
